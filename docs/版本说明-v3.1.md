# WZM 3.10 Next 离线版 v3.1（构建 2026-11-26）

包：`WZM3.10-Next-CN-v3.1.apks`（根目录，2,174,631,934 B，sha256 `3e26033a2049c412…`）
应用名：`WZM3.10 Next`（桌面与最近任务里显示的名字；改的是 `resources.arsc` 字符串池，资源 id 不变）
来源：手机 agent 的 `new/WZM-Next-CN-v3.1.apks`，我只回退了一处下载/流送逻辑，其余原样继承。

## 这一版和 v3 的差别
| | v3 | v3.1（本包） |
|---|---|---|
| 纹理串流 | 被强制关闭（`stream_http=0`、prefetch=0）→ 全场景低清 | **不再写**，引擎按启动时的配置走 |
| 菜单 | 旧版 | 全部动作 `pcall` 保护、队伍人数 3–6、人机数量可控、佛丹斯克未就绪有提示 |
| 全解锁 | 无条件解锁 | 只解锁"当前工程里确实存在"的条目 |
| 线程 | 无 | `labApplySched`：主/渲染大核，其余分簇 |
| 应用名 | WZM3.10 Lab | **WZM3.10 Next** |
| 启动页 / 关于按钮 | 有 | 不变（`base.apk` 只换了应用名与启动页） |

## 为什么把流送改写退回去
- v3 把 `stream_http` 和 `stream_http_prefetch` 都写 0，想避开离线包的 connect/recv 超时，
  代价是 mip 不再抬升 → 贴图低清。
- v3.1 把 `stream_http` 改回 1，但 `prefetch` 仍被钉成 0。你报的"下载高清模型概率闪退 /
  模型 PBR 不完整"正好对应 prefetch 被掐：流送队列拿不到完整数据。
- 本包两个 dvar 都不再写，回到 v14 之前的状态；`out.json` 的 `stream` 字段只做只读上报。

## 装法
```
adb install-multiple -r --no-streaming work/tmp/install/base.apk work/tmp/install/arm.apk \
  work/tmp/install/en.apk work/tmp/install/xx.apk work/tmp/install/asset.apk
```
或在仓库里 `python work/lab.py install WZM3.10-Next-CN-v3.1.apks`（同一个包，就地升级、保留数据）。

## 装机后怎么确认
1. `python work/lab.py status` → `stream` 应为引擎自己的值（预期 `stream_http=1`、
   `stream_http_prefetch=1`）；若仍是 0，说明设备上残留了旧 config，删掉
   `/sdcard/Android/data/com.activision.callofduty.wzm310x/files/config.json` 再启动。
2. 启动页标题仍是「WZM 3.10 Next 离线版 by BroNekoX」，主菜单右上角仍是「关于」。
3. 对局里贴图应为高清；连续下一两局观察是否还有闪退。
